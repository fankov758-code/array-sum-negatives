# Шаг 1: Формулировка алгоритма
Для корректного решения задачи необходимо выполнить следующие действия:

Поиск индексов: Найти индекс первого максимального элемента (idx_max) и первого минимального элемента (idx_min) в массиве.
Определение границ: Так как мы ищем элементы, находящиеся между ними, нам нужно определить левую и правую границу диапазона поиска.
Левая граница: start = min(idx_max, idx_min) + 1
Правая граница: end = max(idx_max, idx_min)
Вычисление суммы: Пройти циклом в интервале от start до end (исключая сам end) и просуммировать только те элементы, которые строго меньше нуля.
Обработка крайних случаев: Если массив пустой, содержит менее 3 элементов, или минимальный и максимальный элементы находятся рядом (соседствуют), то элементов между ними нет, и программа должна безопасно вернуть 0.

# Решение кейс-задачи по нахождению суммы отрицательных элементов одномерного массива, расположенных между максимальным и минимальным элементами.

## Формулировка задачи
Дан одномерный массив $A$ размерности $N$. Требуется найти сумму отрицательных элементов, расположенных строго между максимальным и минимальным по значению элементами.

## Используемый алгоритм
1. Поиск глобального максимума и минимума в массиве и определение их порядковых индексов.
2. Локализация среза индексов, находящихся строго между ними: `(min_idx + 1) ... (max_idx - 1)`.
3. Линейный обход полученного среза с накоплением суммы всех отрицательных значений ($x < 0$).

## Запуск проекта

1. **Запуск программы консольного ввода:**
   ```bash
   python main.py
   ```
   *Пример ввода:* `1 10 2 -3 0 -10 7`
   *Результат:* `Сумма отрицательных элементов между min и max: -3`

2. **Запуск юнит-тестов для проверки корректности:**
   ```bash
   python -m unittest test_main.py
   ```
